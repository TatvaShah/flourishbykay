# Flourish by Kay

Marketing site for [Flourish by Kay](https://www.instagram.com/flourishbykay.co/) in Durham Region and the GTA. Custom bouquets, bridal, graduation, centerpieces, and a flower bar. A 50% non-refundable deposit is stated on the Instagram bio and confirmed in the DM.

This is not the Oregon florist that has used a similar name.

npm install
npm run dev -- --port 4323
